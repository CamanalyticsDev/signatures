# Signatures email CamAnalytics

Images publiques utilisées par les signatures Gmail de l'équipe (photo, icônes, logo animé).
Les signatures chargent ces fichiers via `https://raw.githubusercontent.com/CamanalyticsDev/signatures/main/images/...` :
ne pas renommer ni supprimer un fichier utilisé, sinon l'image disparaît des emails déjà envoyés.
